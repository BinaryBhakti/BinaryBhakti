Overview

GitHub shows README.md from the repo named after the user on their profile. GitHub's markdown strips inline <svg>, so every custom card is a separate .svg file embedded with <img>. Every card is drawn by one script, scripts/build_cards.py, which reads the contribution calendar through GitHub GraphQL. Inside an <img> the SVG is sandboxed (no scripts, no network) but its own <style> runs, so motion is CSS keyframes and fonts (Instrument Serif and Schibsted Grotesk, subset to ASCII) are embedded as base64 woff2. Each element's base style is its final frame and keyframes animate from hidden, so prefers-reduced-motion and STATIC=1 both just drop the animations. Counters count up with one <text> per frame, because CSS can't change text content. The layout follows avivashishta.com/blog/github-profile-readme-animated-svg-cards and github.com/AviVashishta29: the README column is 880px, full cards are 880 wide and thirds 293.333 wide, the 12px gaps are baked into each SVG (so the README has no blank lines or spaces between images), and animation delays run on one page-wide timeline so the page plays top to bottom.

Data and privacy

Only public GitHub data is used. The Action uses the built-in GITHUB_TOKEN, so the repo count is public repos only. The contribution calendar shows private contributions as counts only if that is switched on in your GitHub profile settings; repo names are never shown. Nothing calls third-party services and no secrets are stored in the repo.

Limits and cost

  • Free: GitHub Actions minutes (under a minute a day).
  • Each card is 40–110 KB because fonts are embedded per file; the script asserts every card stays under 250 KB.
  • The README must keep each row of thirds on one line with no spaces, or GitHub adds gaps and the row wraps.
  • SVG text does not wrap, and fonts only cover printable ASCII plus · → — ’ ↑. Keep copy short and inside that set, or re-subset the fonts.
  • Cards use the light theme only; dark-mode viewers see light cards.

Run and deploy

python3 scripts/build_cards.py           # regenerate assets/*.svg (needs gh logged in)
STATIC=1 python3 scripts/build_cards.py  # still final frame, for screenshots
gh workflow run cards.yml                # re-render on GitHub now
git push                            # the profile updates on push
