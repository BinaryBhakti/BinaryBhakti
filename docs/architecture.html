Overview

GitHub shows README.md from the repo named after the user on their profile. GitHub's markdown strips inline <svg>, so every custom card is a separate .svg file embedded with <img>. Three sources feed the page: hand-built cards (header, section titles, project and social cards), github-readme-stats cards generated by a daily Action, and github-profile-summary-cards served live from its public API.

Data and privacy

Only public GitHub data is used. The Action uses the built-in GITHUB_TOKEN, which sees public repos only, so private repo counts and languages are not shown. Adding a PAT with repo + read:user would include private repo totals, but not names. The summary-cards API (vercel) receives the username in the image URL. No secrets are stored in the repo.

Limits and cost

  • Free: GitHub Actions minutes (about 1 minute a day), and the public summary-cards API.
  • The public summary-cards instance can rate-limit; if it does, switch to its GitHub Action (needs a PAT secret).
  • SVG text does not wrap and <img> SVGs can't load web fonts. Keep card copy short so wider fallback fonts (Linux) still fit.
  • Cards use the light theme only; dark-mode viewers see light cards.
